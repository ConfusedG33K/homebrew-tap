# homebrew-tap

Custom [Homebrew](https://brew.sh) tap for [Convoy](https://github.com/TheDynamicPunk/Convoy) and [No Rush](https://github.com/amone-labs/no-rush).

## Available Casks

| Cask | App | Upstream |
| --- | --- | --- |
| `convoy` | Native macOS download manager | [TheDynamicPunk/Convoy](https://github.com/TheDynamicPunk/Convoy) |
| `no-rush` | Menubar app that plays pure nature soundscapes for focus, rest, and sleep | [amone-labs/no-rush](https://github.com/amone-labs/no-rush) |

## Installation

Install a cask directly using:

```bash
brew install --cask ConfusedG33K/tap/convoy
brew install --cask ConfusedG33K/tap/no-rush
```

Or tap the repository first:

```bash
brew tap ConfusedG33K/tap
brew install --cask convoy
brew install --cask no-rush
```

## Update

To update installed casks when new releases are available:

```bash
brew update
brew upgrade --cask convoy no-rush
```
